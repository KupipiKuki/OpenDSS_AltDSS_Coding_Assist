All catalog defaults match; runtime readbacks matched every value (see RUNTIME RESULT).
- **C1/C0 farad→nanofarad scaling: confirmed.** Engine stores farads; public property is nF: `GetCSeqScale` (Line.pas#L253-L259, setter scale `1.0e-9`), `PropertyScale[ord(TProp.C1)] := 1.0e-9` with `Units_nF_per_length` (LineCode.pas#L300-L306), wrapper docstrings "nf per unit length" (`Line.py#L257-L280`, `LineCode.py#L157-L180`). - **FINDING E-1 (minor) — `Line.switch` description overstates the cited range.** Field: `Line.properties[switch].description`. It claims "setting Switch=True also selects the sequence model". The cited range dss_capi 0.14.5 `Line.pas#L672-L699` sets `SymComponentsChanged := TRUE`, kills linecode/geometry/spacing, sets `r1/x1/r0/x0 := 1.0`, `c1 := 1.1e-9`, `c0 := 1.0e-9`, `len := 0.001`, `ResetLengthUnits` — but does **not** assign `SymComponentsModel := TRUE` (that assignment is in the sequence-property branch at `Line.pas#L640-L652`). Sequence-model selection is only supported indirectly via the `Ordering_First` flag on Switch (`Line.pas#L413-L415`) plus the constructor default `SymComponentsModel := TRUE` (`Line.pas#L982`). All other Switch side effects were runtime-verified exactly (R1=X1=R0=X0=1.0, C1=1.1, C0=1.0 nF, Length=0.001, Units=none). Source: https://github.com/dss-extensions/dss_capi/blob/0.14.5/src/PDElements/Line.pas#L672-L699 . Requested correction: see REQUIRED CORRECTIONS #1.
- **FINDING E-2 (minor) — `LineCode.basefreq` does not record the EPRI page's fixed-default claim.** Field: `LineCode.properties[basefreq].description`. EPRI `https://opendss.epri.com/LineCode1.html` states "BaseFreq = Base Frequency at which the impedance values are specified. Default = 60.0 Hz." The pinned engine 0.14.5 instead uses a circuit-dependent dynamic default: `Basefrequency := ActiveCircuit.Fundamental` (LineCode.pas#L483-L487) with `TPropertyFlag.DynamicDefault` (LineCode.pas#L273-L275); runtime with a 60 Hz circuit read back 60.0. The catalog's `default_value: null` is correct for the pinned target, but the description should note the page-vs-engine difference so a null default is not misread. Source: https://github.com/dss-extensions/dss_capi/blob/0.14.5/src/General/LineCode.pas#L273-L281 and #L483-L487 . Requested correction: REQUIRED CORRECTIONS #2.
- **FINDING E-3 (optional traceability) — property-level `source_refs` are sparse.** Only selected rows carry `source_refs` (name, bus1, bus2, linecode, length, c1, c0, basefreq, switch, seasons, ratings, linetype, epsrmedium, wires, neutral, repair); the remaining rows rely on element-level `sources`.
